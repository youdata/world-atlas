# World atlas — lights, rivers, relief

Night lights, rivers and relief of the whole world in one deep-zoom page, with place search and a narrated tour.

Live: https://youdata.github.io/world-atlas/

The page holds no images: its tiles are in [world-tiles-earth](https://github.com/youdata/world-tiles-earth) (night lights, relief) and [world-tiles-rivers](https://github.com/youdata/world-tiles-rivers) (rivers by flow, basin, ocean), read from `../world-tiles-*/`.
